# הטיול שלנו ליפן — הוראות פריסה ל-Netlify

## אפשרות א׳ (הכי פשוטה) — Netlify Drop
1. בטרמינל, בתוך התיקייה הזו: `npm install && npm run build` (יוצר תיקיית `dist`).
2. גשו ל-https://app.netlify.com/drop וגררו את `dist` (רק אותה) לתוך הדף.
3. תוך שניות תקבלו כתובת אתר חיה.

## אפשרות ב׳ (מומלץ לטווח ארוך) — חיבור ל-GitHub
1. העלו את כל התיקייה הזו לריפו חדש ב-GitHub.
2. ב-Netlify: Add new site → Import an existing project → בחרו את הריפו.
3. Netlify מזהה אוטומטית את `netlify.toml`. כל push מעדכן את האתר אוטומטית.

## עדכון גרסה קיימת — אילו קבצים משתנים
בעדכון האחרון השתנו **רק שני קבצים**:
- `src/App.jsx`
- `public/data/itinerary.xlsx`

כל שאר הקבצים (main.jsx, index.html, package.json, הגדרות, אייקונים) נשארים כמו שהם — אין תלות חדשה. פשוט דרסו את שני הקבצים האלה ובצעו `git push` (או `npm run build` + גרירת `dist`).
לאחר פריסה, אם נראה שהאתר תקוע — בצעו רענון נקי (במובייל: סגירה ופתיחה של הכרטיסייה; במחשב: Ctrl/Cmd+Shift+R).

## סנכרון הנתונים — קובץ Excel אחד, חמישה גיליונות
`public/data/itinerary.xlsx` מכיל חמישה גיליונות לעדכון: **לוז**, **טיסות**, **מלונות**, **תקציב**, **אריזה**.
1. מלאו שורה אחת לכל פריט בגיליון המתאים. מחקו את שורת הדוגמה בכל גיליון.
2. עמודות עם רשימה נפתחת (מקום / קטגוריה / מטבע / שולם?) — לחצו על התא ובחרו מהרשימה.
3. שמרו באותו שם ומיקום, ואז: `git add . && git commit -m "עדכון" && git push`.
4. Netlify בונה מחדש אוטומטית תוך דקה-שתיים.
5. פריטים שמוסיפים ישירות באפליקציה מסומנים 🔒 "מקומי אצלי בלבד" ולא נמחקים בסנכרון הבא.

### גיליון 'טיסות'
עמודות: תאריך (YYYY-MM-DD) · שעה (HH:MM) · שדה מוצא · שדה יעד · חברת תעופה · מס׳ טיסה · קישור לכרטיסים · שולם? (כן/לא) · הערות

### גיליון 'מלונות'
עמודות: שם המלון · עיר / אזור · תאריך צ׳ק-אין (YYYY-MM-DD) · מספר לילות · קישור Google Maps · מחיר · מטבע · שולם? (כן/לא) · הערות

הטיסות והמלונות מוצגים באפליקציה בלשונית אחת ("טיסות ומלון") עם מתג לבחירה בין השניים. אפשר גם להוסיף טיסה/מלון ישירות באפליקציה — אלה נשמרים מקומית במכשיר ומסומנים 🔒.

## עבודה אופליין
האפליקציה שומרת את **הנתון האחרון שהצליחה לטעון בהצלחה** (מזג אוויר, שער חליפין)
ומציגה אותו עם ציון "לא מעודכן" אם אין רשת כרגע. שער החליפין נמשך מ-api.frankfurter.dev
(עם נפילה ל-api.frankfurter.app), ומזג האוויר מ-open-meteo — שניהם עמידים לכשל חלקי:
כשל של עיר/מקור בודד לא מפיל את שאר הנתונים.

## שמירת נתונים אישיים (מקומי, לכל מכשיר בנפרד)
App.jsx לעולם לא נוגע ישירות ב-localStorage — הוא תמיד קורא דרך `window.storage`
(ראו `src/main.jsx`). המשמעות: בעתיד, כדי לתמוך במשתמשים מרובים עם סנכרון בין
מכשירים, צריך להחליף רק את הפוליפיל הזה בקריאות לשרת אמיתי (Supabase/Firebase) —
App.jsx כולו נשאר כמו שהוא. גיבוי והעברה בין מכשירים זמינים דרך "גיבוי וסנכרון" בלשונית מידע.

## התקנה על מסך הבית בנייד
- **iPhone (Safari):** שיתוף → "הוסף למסך הבית".
- **Android (Chrome):** תפריט שלוש נקודות → "התקן אפליקציה".
