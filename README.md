# הטיול שלנו ליפן — הוראות פריסה ל-Netlify

## אפשרות א׳ (הכי פשוטה, בלי התקנות) — Netlify Drop
1. במחשב, פתחו טרמינל בתוך התיקייה הזו והריצו:
   ```
   npm install
   npm run build
   ```
   זה ייצור תיקייה בשם `dist`.
2. גשו לכתובת https://app.netlify.com/drop
3. גררו את תיקיית ה-`dist` (רק אותה, לא את כל הפרויקט) לתוך הדף.
4. תוך שניות תקבלו כתובת אתר חיה. אפשר לשנות שם באתר (Site settings → Change site name).

## אפשרות ב׳ (מומלץ לטווח ארוך) — חיבור ל-GitHub
1. העלו את כל התיקייה הזו לריפו חדש ב-GitHub.
2. ב-Netlify: Add new site → Import an existing project → בחרו את הריפו.
3. Netlify יזהה אוטומטית את `netlify.toml` (build command: `npm run build`, publish: `dist`).
4. Deploy site — מכאן כל push ל-GitHub יעדכן את האתר אוטומטית.

## סנכרון הלו"ז דרך קובץ Excel (חדש!)
1. פתחו את `public/data/itinerary.xlsx` (כבר נמצא בפרויקט, עם דוגמה ורשימות נפתחות).
2. מלאו שורה אחת לכל פריט בלו"ז, בגיליון "לוז". מחקו את שורת הדוגמה.
   עמודות "עיר/מקום" ו"קטגוריה" הן רשימה נפתחת (dropdown) — כך שהאפליקציה תזהה נכון.
3. שמרו את הקובץ **באותו שם ובאותו מקום** (`public/data/itinerary.xlsx`).
4. `git add . && git commit -m "עדכון לוז" && git push` — Netlify יבנה את האתר מחדש אוטומטית תוך דקה-שתיים, והלו"ז יופיע עם כל הצביעה לפי קטגוריה.
5. פריטים שמוסיפים ישירות באפליקציה (מקומי) לא נמחקים בסנכרון הבא — הם נשמרים בנפרד ומתמזגים אוטומטית לפי שעה עם הלו"ז מהאקסל.


האפליקציה נבנתה במקור בתוך Claude.ai שם יש API פנימי לשמירת מידע (`window.storage`).
כדי שהיא תעבוד גם כאתר עצמאי, קובץ `src/main.jsx` כולל "פוליפיל" שמממש את אותו API
באמצעות `localStorage` של הדפדפן — כך שכל הקוד ב-`App.jsx` עובד בלי שינוי.

המשמעות: הנתונים (הלו"ז, ההוצאות, האריזה) נשמרים **מקומית בדפדפן/במכשיר** שבו
משתמשים באתר, ולא מסונכרנים אוטומטית בין מכשירים. אם תרצי גישה מסונכרנת מכמה
מכשירים (למשל גם מהטלפון שלך וגם מזה של בן/בת הזוג), יהיה צורך בשרת/מסד נתונים
אמיתי (למשל Supabase או Firebase) — זו הרחבה שאפשר לבנות בהמשך אם תרצי.

## התקנת האתר על מסך הבית בנייד (חוויה הכי טובה)
לאחר שהאתר עולה ב-Netlify:
- **iPhone (Safari):** פתחו את הקישור → כפתור שיתוף (הריבוע עם החץ) → "הוסף למסך הבית".
- **Android (Chrome):** פתחו את הקישור → תפריט שלוש נקודות → "הוספה למסך הבית" / "התקן אפליקציה".

כך האתר ייפתח במסך מלא בלי סרגלי דפדפן, ממש כמו אפליקציה טבעית.
